# Python-Guessing-Game
I have created a game in python as a beginner which requires the player to guess a random number set by python from 1 to 150 in a set number of lives. The aim of the game is to get to the number as quick as possible whilst losing the least number of lives/

![Python Guessing Game screenshot](Images/Screenshot%202026-09-20%20at%2017.07.45.png)

# How to play the Game!
Install the .dmg file which is on the git hub release and then start guessing! The game can only be played on Mac so that is the reason for there only being a .dmg file.
