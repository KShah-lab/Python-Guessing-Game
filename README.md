# Python-Guessing-Game
### I have created a game on python where the aim is to guess a random number set by python in a fixed number of lives. To be able to win the game, you must narrow down the options before you run out of lives. Once you lose all your lives, you must restart the game to have another chance at winning,

# How to play the Game!
#### 1. Make sure to install Python 3 from python.org to ensure you download it safely.
#### 2. The game requires pygame for sound effects and colorama for text colors. To be able to play the game on your computer with no downloads, open terminal on Mac and command prompt on windows and run the following: pip install pygame coloroma
#### For Windows, open command prompt and open the file where the game is saved and type python Guessing Game.py
#### For Mac, open terminal press enter and go to the file where the game is saved and type python3 Guessing\ Game.py
#### This installs all that is needed for the game to run as designed.

# Game play instructions
#### The game secretly chooses a number between 1 and 150.
#### You get 8 lives.
#### Type your guess only as a number and press Enter
#### The game tells you “It’s a bigger number!” → your guess was too low or “It’s a smaller number!” → your guess was too high
#### If you guess correctly You get a bright green message and a A “Well done” message appears.
#### If you lose all lives you get a bright red Game Over and you must restart the game to play again
